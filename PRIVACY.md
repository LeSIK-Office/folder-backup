# Privacy

Folder Backup runs locally. It does not include analytics, advertising, accounts,
cloud uploads or a telemetry service. Folder Backup itself does not send backup
contents or diagnostic reports to its developer.

The app reads the source folders you choose and writes backups to the destination
you choose. Restoring creates a new folder. macOS may ask for permission to access
protected folders, removable drives or network volumes.

Settings include selected paths, access bookmarks, schedules and run history.
They are stored locally in the app's Application Support folder. Backups contain
file names, file contents and metadata needed to restore your files. Diagnostic
details can contain paths; review them before sharing them in a public issue.

Backups are not encrypted by this app. Access to a backup drive can expose its
contents. Use storage protection appropriate to the files you keep there.

Removing the app does not remove its settings or saved backups. The app can
register a login item when you enable that setting. Closing its window keeps it
running in the menu bar; use **Quit Completely** to stop it.
