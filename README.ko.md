# Folder Backup

<img src="Resources/FolderBackupMark.png" alt="Folder Backup 아이콘" width="96">

**필요한 폴더만 간편하게 백업하는 무료 오픈소스 macOS 앱입니다.**
원본 폴더와 저장 위치를 고르면 변경분을 추가로 보관하고, 원하는 날짜의 전체 내용이나
선택한 파일만 새 폴더로 복원할 수 있습니다.

[검증 범위와 남은 항목](docs/VALIDATION-SUMMARY.md)을 확인하세요.

## 어떤 앱인가요?

Mac 전체 대신 프로젝트·문서 등 특정 폴더만 골라 외장 드라이브 등에 보관하려는
사용자를 위한 앱입니다. 폴더 선택, 예약, 버전 보관과 복원을 한곳에서 관리합니다.

- **폴더 단위 백업:** 기존 폴더 하나 또는 여러 개를 하나의 계획으로 관리합니다.
- **변경분 추가 저장:** 같은 계획 안에서 동일한 파일 내용을 여러 버전이 공유합니다.
- **날짜별 복원:** 목록을 검색하고 전체·폴더·파일 단위로 새 폴더에 복원합니다.
- **중단 후 이어받기:** 복사한 데이터를 보존하고 다음 실행에서 재사용 가능 여부를 확인합니다.
  미완료 실행은 완료본으로 표시하지 않습니다.
- **예약:** 수동·연속·매시간·매일·매주·매월을 지원합니다.
- **보관 관리:** 전체·최신 1개·최근 N개 보관과 개별 완료본 휴지통 이동을 제공합니다.
- **용량 표시:** 날짜·개수·복원 용량·이번에 새로 저장한 내용·실제 사용량을 구분합니다.
- **무결성·메타데이터:** SHA-256 검증, 숨김 파일·빈 폴더·심볼릭 링크·권한·확장 메타데이터를 처리합니다.
- **작은 파일 묶음:** exFAT에서는 시스템 SQLite에 작은 파일 내용을 묶어 할당량 낭비를 줄입니다.
- **메뉴 막대 상주:** 창을 닫아도 예약을 유지하며 로그인 시 실행을 설정할 수 있습니다.
- **5개 언어 내장:** 자동 언어 선택과 수동 변경을 제공합니다.

특정 제조사 드라이브가 필요하지 않습니다. macOS에서 접근하고 쓸 수 있는 위치를
선택합니다. APFS·exFAT에서 직접 검증했으며 NAS·네트워크 볼륨이나 모든 파일시스템
조합의 신뢰성까지 확인한 것은 아닙니다.

## 다운로드·설치

1. [Releases](https://github.com/LeSIK-Office/folder-backup/releases)의
   **`v1.6.0-beta.1`**에서 `FolderBackup-1.6.0-beta.1-universal.zip`을 받습니다.
   GitHub의 **Source code** 파일은 소스이며 설치된 앱이 아닙니다.
2. 필요하면 함께 제공하는 `SHA256SUMS`와 ZIP의 체크섬을 대조합니다.

   ```sh
   shasum -a 256 FolderBackup-1.6.0-beta.1-universal.zip
   ```

   파일의 일치 여부를 확인하는 검사이며 Apple 서명·공증을 대신하지 않습니다.
3. 압축을 풀고 **Folder Backup.app**을 **응용 프로그램** 폴더로 옮겨 실행합니다.
4. 현재 앱은 Apple 공증을 받지 않아 첫 실행이 차단될 수 있습니다. 출처를 신뢰한다면
   **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**에 해당 앱의 허용 항목이
   있는지 확인하세요. macOS 버전·관리 정책에 따라 허용 여부가 다릅니다.
   [Apple 공식 안내](https://support.apple.com/ko-kr/102445)를 따르고 시스템 전체 보안은
   끄지 마세요. 악성 소프트웨어 감지 경고가 나오면 실행을 중단하세요.
5. 사용할 원본 폴더·이동식 드라이브 접근을 허용합니다. 보호된 폴더나 회사 관리 Mac에서
   거부되면 해당 권한 설정 또는 관리자 정책을 확인합니다.

사용자가 Apple 개발자 프로그램에 가입할 필요는 없습니다. 앱 ZIP에는 별도 패키지
관리자·실행 환경도 필요하지 않습니다. 다른 Mac에서 다운로드한 사본의 실행은 아직
검증하지 않았습니다.

## 첫 백업과 복원

1. **새 백업**에서 계획 이름과 원본 폴더를 선택합니다.
2. 저장 위치를 고릅니다. 가능하면 원본과 다른 물리 드라이브를 사용하세요.
   원본과 저장 위치가 서로 포함되거나 원본 폴더끼리 겹치면 안 됩니다.
   앱은 드라이브를 포맷하지 않습니다.
3. **설정**에서 일정·보관 개수·제외 항목을 정합니다.
4. **지금 백업**을 실행합니다. 첫 실행은 전체 내용을 읽고 저장하므로 시간이 걸립니다.
   **백업 카트리지**에 완료본이 나타나는지 확인합니다.
5. **복원** 또는 **복원 및 이력**에서 시점과 필요한 파일을 고릅니다. 새 폴더에
   복원하며 원래 위치 옵션도 원본 옆에 별도 폴더를 만들어 기존 파일을 보존합니다.

중지·실패한 경우에는 선택한 드라이브를 다시 연결하고 표시된 원인을 해결한 뒤
**이어 백업**을 실행합니다. 재사용할 수 있는 복사본은 남아 있습니다. 복원 중
중단되면 숨김 미완료 폴더가 남을 수 있고, 재시도는 새 결과 폴더를 만듭니다.

## 완료본 검사 — 1.6.0 추가

백업 카트리지나 복원·이력의 완료본 옆 **버전 검사**를 누르면 저장된 일반 파일의
SHA-256을 확인합니다. 복원 폴더를 만들거나 백업·원본 파일을 변경하지 않습니다.
진행률과 **검사 취소**를 제공하고 결과 표시를 누르면 검사 시각·개수와 누락·접근 실패·
해시 불일치 경로를 볼 수 있습니다. 미완료 백업은 검사 대상으로 표시하지 않습니다.

**설정 → 예약 일정 → 예약 무결성 검사**에서 매일·매주·매월을 선택합니다. 기본값은
**꺼짐**입니다. 한 번도 검사하지 않았거나 마지막 검사로부터 주기가 지난 완료본을
모두 대상으로 삼으므로 기존 완료본과 새 완료본을 같은 기준으로 처리합니다.
공유 내용은 한 번 읽고 이를 참조하는 모든 파일·버전에 결과를 반영합니다.
백업 작업을 우선하며 앱 실행과 드라이브 연결이 필요합니다.

검사 시각 `lastVerifiedAt`과 결과는 이 Mac의 기존 계획 설정에만 저장합니다.
실패는 해당 버전에 경고로 표시하고 성공은 별도 알림 없이 기록합니다. 취소한 버전을
완료로 기록하지 않으며 이미 끝난 버전의 검사와 이전 결과는 보존합니다.
실제 복원이나 현재 원본 대조가 아니라 저장된 일반 파일 내용과 목록의 일치 검사입니다.
장래 드라이브 고장·실시간 데이터베이스의 일관성을 보증하지 않습니다.

test-restore 아이디어는 제공된 작업 문서의 **@RyanJ_KOL** 제안에서 출발했습니다.
기여 출처 표기이며 해당 사용자의 제품 보증이나 공식 추천을 뜻하지 않습니다.

## 버전이 여러 개면 용량도 배수가 되나요?

완료본마다 **해당 실행의 전체 파일 목록**을 갖고 파일 내용은 공유합니다.
날짜마다 전체 이미지 파일을 하나씩 만들거나, 처음부터 증분을 차례로 적용해야
복원되는 방식이 아닙니다. 날짜 폴더만 분리하지 말고 **계획 폴더 전체**를 보관하세요.

처음에 고유한 내용 50GB, 다음에 새로운 내용 1GB, 그다음 2GB가 저장되면 내용 자체는
약 **53GB**에 목록·메타데이터·파일시스템 할당량·휴지통 사용량이 더해집니다.
3개 버전이라고 자동으로 150GB가 되지는 않습니다. 다만 매번 50GB 전체가 다른 내용으로
바뀌면 150GB에 가까워질 수 있습니다. **파일 단위 중복 제거**이며 블록 단위 증분·압축은
아니므로 큰 파일 일부를 수정해도 그 파일 전체가 새로 저장될 수 있습니다.

원본에서 파일을 삭제하면 다음 완료본의 목록에서 빠집니다. 이전 완료본을 보관하면
삭제 전 내용을 복원할 수 있습니다. 어느 보관 버전에서도 참조하지 않는 내용만
정리 대상입니다. 휴지통 데이터는 비울 때까지 공간을 사용합니다. 자동 보관 정리는
새 백업이 성공한 뒤 수행하며 남은 완료본에 필요한 공유 데이터를 보존합니다.

**복원 용량**은 시점별 논리적 파일 크기라 합산하지 않습니다. **실제 디스크 사용량**은
목록·공유 내용을 포함한 계획 저장소의 할당량입니다. 드라이브 전체 사용량이나 별도로
복원해 둔 테스트 폴더까지 포함하는 수치는 아닙니다.

## 예약·백그라운드 실행

앱이 실행 중이고 Mac이 깨어 있으며 대상 드라이브가 연결되어 있어야 합니다.
창 닫기·Dock의 종료는 메뉴 막대 상주를 유지합니다. **완전히 종료**하면 예약도 멈춥니다.
**설정 → 앱 → 로그인할 때 Folder Backup 실행**을 켜면 로그인 시 시작합니다.
앱이 다시 실행되고 저장 위치를 사용할 수 있으면 놓친 예약을 확인합니다.
잠든 Mac이나 꺼진 Mac을 직접 깨우는 기능은 없습니다.

연속 모드는 약 1분 간격으로 변화를 확인하며 실시간 미러링은 아닙니다.
매월 설정한 날짜가 없는 달에는 말일에 실행합니다. 저장할 변경분이 적어도
원본 항목이 많으면 확인 과정에 시간이 걸릴 수 있습니다.

## 다국어 지원

**한국어·일본어·중국어 간체·영어·스페인어**가 앱에 포함되어 있습니다. 언어팩을 따로
받지 않습니다. 기본값은 **시스템 언어 사용**이며 국가·지역이 아니라 Mac의 첫 번째
언어를 따릅니다. 한국어는 한국어, 일본어는 일본어, 베트남어·프랑스어 등 미지원 언어는
영어로 표시합니다. 중국어 지역 변형은 현재 간체 팩으로 처리하며 번체 팩은 없습니다.

**설정 → 앱 → 언어**에서 강제 변경할 수 있습니다. 앱 문구는 즉시 바뀌고 macOS 기본
메뉴·대화상자는 재실행이 필요할 수 있습니다. 제품명·계획명·파일명·경로는 유지합니다.
각 언어의 UI 맥락에 맞게 작성했으며 외부 원어민 감수는 받지 않았습니다.
[언어 구현 설명](docs/LOCALIZATION.md)을 참고하세요.

## 소스 빌드·구성

macOS, **Swift 6 이상**의 Apple Command Line Tools 또는 Xcode, macOS SDK, Python 3,
zsh가 필요합니다. 외부 Swift 패키지 의존성은 없습니다.

```sh
git clone https://github.com/LeSIK-Office/folder-backup.git
cd folder-backup
zsh scripts/build.sh
```

결과는 `dist/Folder Backup.app`이며 두 아키텍처를 빌드합니다. 기본 서명은 ad-hoc입니다.
버전·빌드 번호는 `Resources/Info.plist`에 있습니다. 현재 배포 빌드는 Apple Silicon,
macOS 27.0.1, Swift 6.2.3 환경에서 만들었습니다. macOS 14 지원 선언과 해당 버전의
실제 실행 검증은 구분합니다.

```sh
swift run -c release BackupCoreChecks    # 핵심 백업·복원 검사
zsh scripts/check-runtime.sh            # 예약·앱 수명주기 검사
zsh scripts/check-release.sh            # 테스트 디스크 장애 검사 포함
zsh scripts/package-release.sh          # 이미 빌드한 앱 포장
```

전체 검사는 수 GB 여유 공간이 필요합니다. 연결 해제·용량 부족 검사는 직접 만든
테스트 이미지에서 수행하며 물리 백업 드라이브를 분리하지 않습니다. 결과물은 보존합니다.
포장 스크립트는 앱과 소스의 일치를 검사하고 개인 기록·기존 Git 이력·백업을 제외한
소스 ZIP·체크섬을 만듭니다. [앱 구성](docs/ARCHITECTURE.md#한국어), [배포 절차](docs/RELEASE.md).

핵심 17개 흐름, 중단·재개·용량 부족·연결 해제·손상 검출과 실제 최신 백업 전체 복원을
검증했습니다. **일반 파일 453,024개·49,796,768,925 bytes의 SHA-256이 모두 일치**했습니다.
exFAT에서 변경분·보관 정리·복원도 확인했습니다. 모든 기기·장애에 대한 보증은 아니며
[검증 요약](docs/VALIDATION-SUMMARY.md)에 범위와 남은 항목을 적었습니다.

## 제한·개인정보·법적 고지

- 폴더 백업 전용입니다. 시스템 전체 복구·디스크 이미지·미러링·클라우드·암호화·압축·자동 앱 업데이트는 없습니다.
- 실행 중 바뀌는 파일은 재시도하고 실행용 소켓·파이프와 사라진 항목은 구분해 보고합니다.
  APFS 시점 스냅샷이나 데이터베이스 전용 일관성 백업은 아닙니다.

  내용·파일명을 읽을 수 있습니다. [개인정보 처리](PRIVACY.ko.md)를 확인하세요.

  저장 형식도 독자 형식입니다. Seagate Toolkit 백업을 가져오거나
  복원하는 기능은 없습니다.

  권리까지 부여하지 않습니다. [개발 경위·법적 범위](docs/LEGAL.md#한국어),
